## Slide 1 — Title + project question

**Visuals**
- Title block: project name + UQ + DATA7901
- One framed question, large font:
  > *"If real investors and simulated agents see the same earnings shock, how closely does the resulting Reddit discussion match?"*
- Small footer: NVDA Q3 FY2026 primary benchmark; AAPL secondary; META exploratory

**Speaker notes (≈60 s)**
Hi everyone — quick intro: this project is about simulating retail-investor discussion around earnings events using open-weight LLMs and then *checking* whether the simulation actually matches real Reddit. The whole project is built around one concrete question, the one on the slide: when real investors and simulated agents react to the same earnings shock, how closely does the resulting discussion match? I picked one primary event — NVIDIA Q3 FY2026 — and use AAPL and META as secondary cases. The point isn't to build the best chatbot; it's to build a *yardstick* for measuring how realistic LLM-driven social simulation actually is.

## Slide 2 — Problem: fluency is not validation

**Visuals**
- Left column: a fluent-looking sample LLM comment (real, from our pilot)
- Right column: three small icons + one-line each:
  - 🎯 **stance** — what mix of bullish / bearish / neutral?
  - ⏱️ **timing** — when do comments arrive?
  - 🔎 **content** — does the language overlap real Reddit?
- Bottom: bold takeaway — *Plausible ≠ realistic.*

**Speaker notes (≈70 s)**
The current LLM-simulation literature has a problem: it stops at *plausibility*. The model produces text that reads like a Reddit comment, and people say "looks good." But a finance simulator has to do more than sound right. It has to get the *crowd pattern* right — the stance mix, the timing, and the content distribution. A simulator can sound like Reddit while completely missing all three of those. That's the gap this project addresses. The whole proposal is framed around catching that gap with explicit measurements rather than vibes.

## Slide 3 — Real Reddit benchmark and curation

**Visuals**
- Embed: `outputs/proposal_support/figures/` benchmark size bar chart (raw vs curated, 3 events)
- Small inline table:

  | Event | Raw | Curated | Retention |
  |-------|-----|---------|-----------|
  | NVDA  | 2641 | 2403 | 91% |
  | AAPL  | 392  | 383  | 98% |
  | META  | 1444 | 344  | 24% |
- Caption: "Manual thread-level curation; wrong-company threads dominate META loss"

**Speaker notes (≈70 s)**
Here's the benchmark side. I collected Reddit discussion from r/stocks and r/wallstreetbets, aligned to a window from 24 hours before to 48 hours after each earnings release. Threads are curated manually at the thread level — I read titles and decide *relevant / marginal / remove*. NVDA keeps 91% of comments because the threads are clean. AAPL keeps 98% but is small. META loses 76% because the Reddit API returned eleven threads about completely different companies that happened during the same earnings week — Alphabet, Reddit, Chipotle, Amazon, and so on. That's why I treat NVDA as the primary benchmark, AAPL as secondary, and META as an exploratory stress test only.

## Slide 4 — Pipeline: real corpus vs simulated corpus

**Visuals**
- Flow diagram (left to right):
  ```
  Reddit JSON API ──► Curation ──► Real corpus (2403 NVDA)
                                          │
                                          ▼
                                    Same metrics
                                          ▲
                                          │
  Event card ──► Qwen LLM ──► Sim corpus (108 per run)
              (prompt + persona)
  ```
- Bottom row: small labels for the two finalist conditions
  - **Stance-first:** Qwen2.5-3B + P0_V0 (9 archetypes)
  - **Semantic-first:** Qwen3.5-2B + P2_V1 (3 broad cohorts)

**Speaker notes (≈70 s)**
The pipeline is symmetric. On one side I have real curated Reddit. On the other side I have simulated comments generated by an open-weight Qwen model, conditioned on a persona description and a hand-written event card. Both sides go through *the same* evaluation metrics, so the comparison is apples to apples. I lock two finalist conditions for the larger reruns: one that's tuned for stance matching — Qwen2.5-3B with the baseline prompt and 9 archetypes — and one tuned for semantic matching — Qwen3.5-2B with a behaviour-first prompt and 3 broad cohorts. Each finalist runs at n=108 comments across temperatures 0.5, 0.7, 0.9, 1.1 and two seeds.

## Slide 5 — Four realism metrics

**Visuals**
- 2×2 grid, one cell per metric. Each cell: icon, one-line definition, lower-is-better arrow.

  | | |
  |---|---|
  | **JSD (stance)** — bullish / bearish / neutral balance | **Wasserstein-1 (timing)** — hourly posting profile, in hours |
  | **MMD (semantic)** — distance between sentence-embedding distributions | **Grounding** — % of comments referencing actual earnings facts |
- Bottom: *Independent diagnostics, not one weighted score.*

**Speaker notes (≈75 s)**
Four independent diagnostics, each measuring something different. JSD compares the stance balance — what fraction of comments are bullish, bearish, or neutral. Wasserstein-1 compares the temporal profile — when do comments arrive relative to the earnings release. MMD compares the semantic content using Sentence-BERT embeddings — does the simulator inhabit the same language space as real Reddit? Grounding is a behavioural check — how often do comments actually reference the earnings facts. Crucially, I report all four *separately*. I deliberately don't collapse them into a single weighted realism score, because the whole interesting question is the *trade-off* between them. Combining them would hide the trade-off.

## Slide 6 — Finalist n=108 results

**Visuals**
- One headline table (just the top three rows for clarity):

  | Run | Model + condition | tau | MMD ↓ | Grounded | Ungrounded |
  |-----|-------------------|-----|------|---------|-----------|
  | **Best** | Qwen3.5-2B + P2_V1 | **1.1** | **0.0653** | 57.4% | 14.8% |
  | 2nd | Qwen3.5-2B + P2_V1 | 0.9 | 0.0783 | 71.3% | 5.6% |
  | 3rd | Qwen3.5-2B + P2_V1 | 0.7 | 0.0966 | 86.1% | 5.6% |

- Side-by-side mini-bar:
  - Real Reddit: **2.5% grounded** | Best LLM: **57.4% grounded**
- One-line callout: *Higher temperature → better MMD, less over-grounding, but still over-grounded vs real (2.5%).*

**Speaker notes (≈80 s)**
This is the headline result. Across the 14 finalist runs at n=108, Qwen3.5-2B with the behaviour-first prompt at temperature 1.1 is the best on semantic similarity — MMD of 0.065. Within that block, as temperature goes up, MMD improves and grounding drops. So temperature is essentially trading factual fidelity for distributional realism — and that's the trade-off the project predicted. But here's the honest framing: even the best run is grounded 57% of the time, and real Reddit is only grounded 2.5% of the time. Real investors react to the news; they don't restate it. The simulator is still over-grounded by more than 20×. So we've made real progress on semantic similarity, but the behavioural realism gap is still very visible.

## Slide 7 — Limitations and next steps

**Visuals**
- Four-row table with status icons:

  | Limitation | Status | Next step |
  |-----------|--------|-----------|
  | Timestamps are scheduler-driven, not LLM-driven | known, by design | document explicitly; Wasserstein measures the scheduler, not the model |
  | Over-grounding (57% vs real 2.5%) | confirmed at n=108 | longer prompts, retrieval-free generation, fact-suppression prompts |
  | Stance labeler is rule-based (κ = 0.45) | hand-audited, moderate agreement | upgrade to FinBERT or zero-shot LLM stance for final report |
  | AAPL cross-event validation pending | scheduled for Semester 2 | adapt pipeline; check whether NVDA finalists transfer |

**Speaker notes (≈75 s)**
Four honest limitations. First — timestamps. The simulator's comment times come from an external Gaussian scheduler that the LLM never sees, so Wasserstein only measures whether *that scheduler* is calibrated, not whether the model's behaviour is realistic. I frame it that way deliberately in the proposal. Second — over-grounding is the biggest remaining behavioural gap; the best LLM still mentions revenue, EPS, and Blackwell far more often than real investors do. Third — the stance labeler is keyword-based with moderate hand-audited agreement, kappa 0.45. It's good enough for distributional JSD but not for individual stance claims. Fourth — AAPL cross-event validation is scheduled for Semester 2 to test whether NVDA-tuned finalists generalise.

## Slide 8 — Takeaway

**Visuals**
- Single large headline:
  > **What I built is a validation framework, not a solved simulator.**
- Three short bullets underneath:
  - A curated benchmark + four independent metrics that any future simulator must beat
  - Honest evidence that current open-weight LLMs improve semantic realism but over-ground 20× vs real Reddit
  - A clear next-stage plan: cross-event, better stance labeling, prompt-level grounding suppression

**Speaker notes (≈65 s)**
Closing message. The contribution of this project is not "a realistic investor simulator" — that would be overclaiming. The contribution is a benchmark and a measurement framework: any future, richer, interactive simulator has to beat this simple one-shot baseline on JSD, MMD, Wasserstein, and grounding *simultaneously*, against a real-vs-real noise floor I've already established. That's a much sharper yardstick than "does it sound like Reddit?" If we get a strong result later, the framework supports cautious use of LLM simulation for behavioural stress-testing. If we get a weak result, the framework tells us exactly *which* dimension is still failing. Either way, the project produces something usable. Thanks — happy to take questions.
